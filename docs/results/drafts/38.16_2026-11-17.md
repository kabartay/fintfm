### What "AP diff" means (and why it is not the difference of the printed means)

From `run_credit_compare` and `paired_auc_difference` (`src/fintfm/evaluation/metrics.py`):

- Direction: **A minus B = `fin00` minus `fin07`**. Positive favours pure SCM.
- `delta` is the AP of the **pooled out-of-fold predictions** (all rows of the panel, each scored once by each checkpoint, from five different fitted models) for A, minus the same for B. It is **not** the mean of per-fold AP.
- The interval is the 95% percentile interval of 2,000 **row** resamples of the pooled rows, recomputing both APs on each resample (paired: the same rows for both checkpoints). Resamples missing a class are skipped. One row is one company in these panels, so a row bootstrap is not the cluster problem of V4FinBench. It does not resample folds or training parts, so it excludes fit-to-fit variation.
- The p-value is two-sided: twice the smaller share of resamples with difference <= 0 or >= 0, floored at 1/(draws+1).
- Holm: adjusted across the **4 panels**, separately for AP and for ROC-AUC. It does not count the AP/AUC pair, nor the other comparisons in the project.

Mean-of-folds difference against pooled difference, so the reader can see the gap (computed from the record):

## Caveats

- One fold assignment (seed 0). Five folds give five dependent estimates, not five independent ones; the bootstrap is over pooled rows, not folds.
- Pooled bootstrap mixes folds fitted on different training parts (code docstring).
- Two checkpoints only, one training seed each; checkpoint-to-checkpoint variation at a fixed mix is not measured (§73's "one checkpoint" caveat remains).
- Boosters, logistic regression and ECE not re-run, so §73's "ratio to best booster" and calibration claims keep their single-split status.
- Observed bankruptcies, so this is a comparison on real data, not coverage against a solver. It is an AP/AUC comparison, not a coverage claim.
- The run shared the machine with the bwa pipeline; wall time (1,935 s) is not a benchmark of speed.
