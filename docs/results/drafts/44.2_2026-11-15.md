## What is established

1. **The cell block closes the cap at matched protocol.** pub-s0 against nocell-s0, same prior,
   seed and task count: Bayes 0.9 regret 0.0015 against 0.2117, antisymmetric 0.9936 against
   0.5929. This extends §172 (AP on V4FinBench) to the two probes 44.2 names. One seed per arm.
2. **Labels are necessary for the cell block to do anything useful, at both seeds.** Removing
   them takes antisymmetric from 0.994 and 0.989 to 0.641 and 0.659, and Bayes regret from
   0.0004 and 0.0006 to 0.445 and 0.440. The unlabelled cell block is worse than no cell block
   on the Bayes probe (0.455 against 0.688 at ceiling 0.9) and on `symmetric_sum` (0.425 and
   0.480 against 0.993). With §250 (the unlabelled checkpoints ignore their context labels),
   this says the unlabelled block does not learn to use the context at all.
3. **A cheaper row-within-feature stage keeps nearly all of the Bayes and antisymmetric
   result.** Replacing full row attention with 64 learned inducing points (labelled, summarising
   each feature's context cells) gives antisymmetric 0.9910 and regret 0.0066 and 0.0012,
   against 0.9936, 0.0015 and 0.0002 for full attention. The regret is about four to six times
   larger but both are far from the nocell arm's 0.21 to 0.23. Single seed, 3 task draws, so the
   size of the gap is not resolved. §178 found the same arm no better on V4FinBench (mean AP
   0.1789 against 0.1975 for the seed 0 control, minus 0.0186, and minus 0.0089 against the
   seed 1 control; the yardstick is 0.0117), so this says nothing in favour of the induced stage
   on real data.
4. **So the all-pairs row attention (the N x N stage) is not what the cap needs**; a
   learned-query summary of labelled per-column context cells is enough on these probes. That is
   the property `cell_mixing="factorized"` (44.3) also relies on, and it is the closest existing
   evidence for it, but it is evidence about the induced stage, not about the factorized block.

## What is not established, and the arm that would establish it

- **The factorized column block itself.** No checkpoint exists. The induced stage pools with
  64 learned queries per feature over that feature's context cells and then lets every cell read
  the summaries; the factorized block uses one query per column plus a cross-column mixing
  layer. They are similar in kind, not the same model.
- **A non-attentional summary** (per-column moments, a pooled statistic with no learned query)
  is not implemented anywhere. Neither the induced stage nor the factorized block is
  non-attentional, so Verify's literal arm is untested. Nothing here says whether the labelled
  summary needs a learned query or whether column moments conditioned on class would do.
- **Whether column-within-row attention is needed** (the other stage): no checkpoint removes it.
- **Seeds.** Every arm above except the two label pairs is a single training seed; the
  seed-to-seed spread of the Bayes regret for cell arms is unmeasured beyond the two label-pair
  seeds (0.0004 and 0.0006 at ceiling 0.9).

**Training ablation for a Kaggle kernel (T4x2, copy `scripts/kaggle/ts_pub_s0`):** recipe
`configs/published/v4-cellattn-labels.yaml` at seed 0, 6,000 steps (48,000 tasks), exactly as
`ts_pub_s0`, plus `--cell-mixing factorized` (cell labels on, `n_cell_blocks` 1,
`cell_row_attn=full`, `readout=pool`, all required by the flag). Name it `ts_factorized_s0`. Score
on the same two probes with `scripts/diag_44_2_ingredients.py` (change its `seeds=3, n_ensemble=4` in the
`bayes_ceiling_report` call to `seeds=10, n_ensemble=8` for the published convention) and compare with pub-s0, nocell-s0 and
dr62-induced-s0 above. Add a second seed for any arm whose regret lands between 0.01 and 0.1.
A literal non-attentional arm needs a new `cell_mixing="moments"` option first (per-column
class-conditional mean and variance of the context cells, added back by an MLP); it is a small
code change but has not been written. Run `uptime` first, per CLAUDE.md.
