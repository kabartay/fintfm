Where this model actually sits

FinTFM is a tabular foundation model for corporate credit risk, pretrained only on synthetic data. This page is its standing under TabArena's protocol, published in full, including the part where it loses.

903 Elo · 107th of 110 · FinTFM with a trained linear readout, all 51 TabArena-Lite datasets (FINDINGS §224, 2026-11-13)

This is not tabarena.ai. It is FinTFM's own TabArena-Lite run: all 51 datasets at one split each, scored against TabArena's cached results for 110 methods, FinTFM included. The official board uses every split, so its Elo values are not comparable to these, even for a method with the same name. Elo is only meaningful relative to the population it was computed over. The real board is at tabarena.ai.

2 entries are not listed on this page; they count in every Elo and every position shown. Rows marked "imputed" had results for some datasets filled in by TabArena; none of FinTFM's are imputed.

What the FinTFM row is. It is not the zero-shot model. A logistic regression (ridge for regression) is fitted on the network's representation of each training split, one per partition leaf for classification; for multiclass and regression it also takes the row's own features. Binary runs on the published checkpoint, multiclass and regression on unpublished checkpoints. These are general-tabular results, not credit results: on real credit panels FinTFM currently loses to gradient boosting (FINDINGS §216).
