Where this model actually sits

FinTFM is a tabular foundation model for corporate credit risk, pretrained only on synthetic data. This page is its standing under TabArena's protocol, published in full — including the part where it loses.

— Elo · — of — methods compared

This is not tabarena.ai. It is FinTFM's own comparison: 27 TabArena-Lite datasets — the subset this model's published checkpoint can run on — at one split each, against a cached snapshot of 95 other methods.

The official board covers all 51 datasets across every split, so its Elo values are not comparable to these, even for a method with the same name. Elo is only meaningful relative to the population it was computed over. The real board is at tabarena.ai.

Two variants of the same weights

The first is the entry submitted to TabArena and withdrawn on competitiveness; it uses the model's own classification head. The second swaps that head for a plain logistic regression fit on the model's internal representation — identical weights, different final layer. Why that helps is written up in full.
