Where this model actually sits

FinTFM is a tabular foundation model for corporate credit risk, pretrained only on synthetic data. This page is its standing under TabArena's protocol, published in full, including the part where it loses.

1023 Elo · 108th of 119 · FinTFM with a trained linear readout, all 51 TabArena-Lite datasets (FINDINGS §304, 2026-11-19)

This is not tabarena.ai. It is FinTFM's own TabArena-Lite run: all 51 datasets at one split each, scored against TabArena's cached results for 119 methods, FinTFM included. The official board uses every split, so its Elo values are not comparable to these, even for a method with the same name. Elo is only meaningful relative to the population it was computed over. The real board is at tabarena.ai.

2 entries are not listed on this page; they count in every Elo and every position shown. Rows marked "imputed" had results for some datasets filled in by TabArena; none of FinTFM's are imputed.

What the FinTFM row is. It is not the zero-shot model. A linear model (logistic regression for classification, ridge or random-Fourier-feature ridge for regression) is fitted on the network's representation of each training split, one per partition leaf, and also takes the row's own features. Size-gated levers: four readout bags and spline features for small binary tables, one-hot indicators and spline features for multiclass, a random-Fourier-feature readout for small regression tables and spline features for all regression tables, with regression predictions clipped to the training target's range widened by 10% (FINDINGS §283, §286, §290, §293, §301). The board is the reproduction from the pull-request branch (fork 1aa50af) with no environment overrides, on Kaggle CPU, Kaggle and Hugging Face T4 GPUs and a Mac CPU, scored against the 119 methods of TabArena’s collection at upstream main; the same runs are 1,019.6 Elo, 99th of 110, on the fork’s older collection (FINDINGS §297, §303, §304). The binary, multiclass and regression checkpoints are all public under Apache-2.0 (fintfm 0.12.0). These are general-tabular results, not credit results: on real credit panels FinTFM currently loses to gradient boosting (FINDINGS §216).
